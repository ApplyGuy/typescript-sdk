# Contributing

Thanks for helping improve the Apply Guy TypeScript SDK.

1. Create a branch from `main`.
2. Run `npm ci`.
3. Make the change and add or update tests.
4. Run `npm run check`.
5. Open a pull request describing the API behavior being changed.

Public API changes should remain backward compatible whenever possible. Never
commit API keys, access tokens, candidate data, resumes, or live application
payloads.
